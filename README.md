# Aprender Brincado

Catálogo em português de jogos educativos para imprimir em casa ou na escola. Abra index.html no navegador. O site e os PDFs funcionam offline após baixar o projeto inteiro.

| Atividade | Material incluído | Habilidade |
| --- | --- | --- |
| Bingo do quintal | Duas cartelas e seis peças de sorteio | Vocabulário e associação de imagens |
| Feira dos números | Seis pedidos e seis bancas | Contagem de 1 a 6 |
| Pares de bichos | Doze cartas | Memória visual |

## Referências e decisões

| Referência pesquisada | O que aproveitamos |
| --- | --- |
| [Aprender Brincando, de Francy Braz](https://francybraz.wixsite.com/aprenderbrincando) | Material digital imprimível e participação da família. O bingo inspirou um jogo de quintal com cartelas próprias. |
| [Twinkl Brasil](https://www.twinkl.com.br/) | Melhor referência para a navegação do acervo: a divisão por assunto ajuda o adulto a escolher. Aqui há filtros por linguagem, matemática e memória. |
| [Escola Games, ficha do Letrinhas](https://www.escolagames.com.br/jogos/letrinhas/ficha) | Objetivo pedagógico junto de cada jogo, com instruções para o adulto. |

Os três jogos desta edição são gratuitos, com download direto. Textos, regras e composição das fichas foram preparados para este projeto. As figuras dos PDFs usam glifos da fonte Noto Color Emoji.

## Manutenção

A página inicial destaca o bingo gratuito. O catálogo em produtos.html contém as fichas e os filtros. A pasta imagens/ traz amostras dos PDFs. O arquivo style.css controla as cores e o layout. O arquivo catalogo.js filtra os jogos pelo atributo data-topic. Os PDFs ficam em materiais/. Ao adicionar um jogo, inclua seu PDF e uma ficha com o mesmo padrão das existentes. O site pode ser servido por qualquer hospedagem estática.
